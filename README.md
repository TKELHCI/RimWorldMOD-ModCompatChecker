## Features / 功能

Automatically scans Harmony patch conflicts, XML Def overrides, missing dependencies, and load order issues. Optionally connects to an AI API (DeepSeek / OpenAI / Anthropic compatible) for diagnostics.  
自动扫描 Harmony 补丁冲突、XML Def 覆盖、依赖缺失和加载顺序问题。可选接入 AI API（兼容 DeepSeek / OpenAI / Anthropic）进行诊断。

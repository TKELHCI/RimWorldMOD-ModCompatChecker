[v1.7] — 2026-06-03
━━━━━━━━━━━━━━━━━━━━━━
New:
- API 监控面板: 实时追踪所有 API 调用 (测试连接/AI分析/批量扫描/追问等), 40条上限
- API 阻止开关: 一键阻止本 MOD 所有后续 API 访问, 不影响其他 MOD
- API 余额检测: 定时查询 DeepSeek/OpenAI 余额, 低于阈值事件警告
- AI 响应自我审查: 本地正则检测 AI 回复中的危险建议 (文件写入/代码执行/注册表等)
- 自我审查事件通知: 检测到危险 → 以袭击事件形式弹窗警告
- 测试模式: 高级选项中启用, 可手动触发安全警告演示和循环报错演示
- API 详细设置折叠栏: 模型选择/API Key/超时/测试连接收纳进子面板
- Prompt 注入过滤: 发送给 AI 的报错日志自动过滤恶意注入模式
- 板块红色分隔线: 5 个主分区之间视觉区分
- API 隐私提醒: API Key 输入框旁标注数据流向

Changed:
- API 设置重构: API详细设置/余额检测/API监控 三层折叠结构
- 强制停止按钮始终可见 (不再仅运行中显示)
- 日志文件大小监控: 图标箭头修复 (▶/▼)
- 高级选项: AI 预设描述/自我审查说明/测试模式提示 动态高度适应多语言

Fixed:
- 修复 WriteSettings 每帧写磁盘 → 仅 API Key 变更时写入
- 修复 API 监控滚动条内容高度计算 (详情行未计入)
- 修复双重锁 (StartErrorAnalysis 内嵌套 lock)
- 修复 3 处箭头字符丢失 (▶ → ?)
- 修复 EnableSelfAudit 未持久化 (未写入 ExposeData)
- 修复自我审查警告正文硬编码英文 → 8 种语言翻译
- 修复 csproj 格式 (两标签挤同一行)
- API 监控换档/回主菜单自动重置
- 8 种语言补齐 32 个新增翻译键

[v1.6] — 2026-06-02
━━━━━━━━━━━━━━━━━━━━━━
Changed:
- 界面重构: 所有 5 个分区 (API设置/兼容性分析/报错日志/工具箱/高级选项) 默认折叠，按需展开
- 移除 MOD 更新检测 — 与兼容性分析存在冲突
- 移除关系链分析 — 功能未稳定，重新设计后再加入
- MOD 名称改为中英双语: "Mod 兼容性检查器 (Mod Compatibility Checker)"
- 高级选项: 移除 UseCustomSystemPrompt 复选框，改为始终显示可编辑文本区
- 3 个 AI 预设指令按钮: 简洁诊断 / 详细分析 / 新手友好，点击即应用，附带描述说明
- 预设指令根据游戏界面语言自动切换中/英文

Fixed:
- 修复 Tools/Advanced 分区渲染坐标错误 (listing → inner)
- 修复兼容性分析窗口重复调用 inner.End() 导致的潜在异常
- 修复英文版依赖分析 PromptBuilder 未调用 GetSystemPrompt() 导致自定义预设失效
- 清理 3 处死代码: _updateScroll, _encycloScroll, DrawRelSection
- 补充 9 个缺失翻译键，8 种语言各 316 keys 对齐
